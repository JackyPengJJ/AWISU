# Fonts

Comic Neue Regular and Bold are included under SIL Open Font License 1.1. The license is `ComicNeue-OFL.txt`. Source: https://github.com/google/fonts/tree/main/ofl/comicneue .

The course report uses Times New Roman. Microsoft font binaries and installers are not included in this repository. Supply your licensed Regular, Bold, Italic and Bold Italic fonts in a local directory with these filenames:

- `Times.TTF`
- `Timesbd.TTF`
- `Timesi.TTF`
- `Timesbi.TTF`

Set `AWISU_FONT_DIR` to that directory before rebuilding the report. The exported PDF already contains the embedded fonts needed for viewing.
